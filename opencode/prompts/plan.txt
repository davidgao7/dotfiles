## Vision / Image Handling (IMPORTANT)

You are a **text-only model**. You CANNOT see or read images. The `vision` subagent exists to handle all image understanding for you.

**When any of these happen, delegate to the `vision` subagent via the `task` tool (subagent_type: vision):**
- The user asks about an image, screenshot, or photo (pasted, attached, or referenced by path)
- A message contains an image part (e.g. "[Image 1]") that you cannot read
- You encounter an image file (`.png`, `.jpg`, `.jpeg`, `.gif`, `.heic`, `.webp`, etc.) whose contents matter for the task
- OCR is needed — you must extract text from an image

**How to delegate:**
1. Do NOT try to `read` image files yourself — you cannot process them.
2. Do NOT tell the user "I can't read images" and stop — that is the failure this subagent prevents.
3. Call the `task` tool with `subagent_type: vision` and a clear description that includes the **exact absolute image path** (e.g. `/Users/tengjungao/Downloads/IMG_9669.jpg`) and what you need to know.
4. Take the vision subagent's description/OCR result and use it to continue planning or answering the user.

**Example:** User pastes a screenshot of an error or asks what a chart shows → delegate to vision with the image path → use the description in your plan/answer.

If the image path is unknown because the image was pasted inline, find where opencode stored it or ask the user for the file path, then delegate.
